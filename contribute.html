Contribute

Add a proverb.

Share a proverb, translation, or correction through a GitHub issue, a public submission for review.

Contribute on GitHub

You need a free GitHub account. Nothing is saved on this page. Submit the completed issue on GitHub to send your contribution.

Issues are public. Do not include your email address or other private information. Use a public name or GitHub handle for credit.

What we need

  • The proverb in its original language and script.
  • The language and region or tradition.
  • A transliteration, which writes the sounds in Latin letters, if the original uses another script.
  • A word-for-word English translation and an explanation of the meaning.
  • Equivalent proverbs in other languages, if you know them.
  • A source, such as a book, archive, or family tradition. State where you learned it.

What happens next

  1. Submit the issue on GitHub. It becomes part of the public review record.
  2. A maintainer reviews the source, translation, and meaning. Questions and corrections stay in the issue.
  3. Accepted contributions enter a future collection update with contributor credit. Submission does not mean acceptance or immediate publication.

Share only material you have the right to contribute under CC BY-SA 4.0.

For a large collection or archive, use the same issue template. Describe its scope and sources before attaching files.

Browse the repository or read existing contributions before submitting.
